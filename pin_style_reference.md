Golden examples from Pin Perfect Pro. Use these to train image generation and copy prompts.

## MASTER PATTERNS — Learned from 11 Real Pin Perfect Pro Examples

### RULE 1: Product Color = Pin Color
ALWAYS match the pin's color palette to the actual product packaging.
- CeraVe (white + blue jar) → white + blue pin
- Laneige (pink/red jar) → pink + coral pin
- e.l.f. Halo Glow (nude/champagne bottle) → warm beige + champagne pin
- Medicube (white + blue lid) → white + blue clinical pin
- Neutrogena Hydro Boost (bright blue jar) → bright blue + aqua pin
- Liquid IV (teal + yellow) → teal + lemon yellow pin
- Bloom Greens (soft green jar) → soft green + pink pin
- Theragun (matte black) → dark + neutral tones pin
NEVER use a generic pink/blush palette for every beauty product.

### RULE 2: Background Depends on Niche
- **Beauty/Skincare**: Clean white or light beige background with soft shadows. Product hero on its own — no room scene. Exception: add texture swatch or water droplets if the product has a notable texture.
- **Home Decor**: ALWAYS lifestyle room scene — sofa, plants, candles, blankets. People need to visualize it in their space. Never plain white background for home decor.
- **Fitness/Wellness**: Fresh ingredients around the product (citrus for Liquid IV, berries for Bloom). Or lifestyle usage shot (woman using Theragun). Show the product being used or enjoyed.

### RULE 3: Headline Formula by Type
- **Skincare**: Question or benefit promise — "Best Moisturizer for Dry Skin?" / "Clear Pores Fast" / "Hydration + SPF in One"
- **Beauty/Makeup**: Use the product's own language as the hook — "Glow Like a Filter" / "Dry Lips Overnight Fix"
- **Home Decor**: Outcome/feeling-focused — "Cozy Lighting Upgrade" / "Cozy Home Must-Have"
- **Fitness**: Pain point or action — "Beat Bloating Fast" / "Relieve Muscle Pain Fast" / "Hydration On the Go"
- Always include the product name in subheadline directly below
- Add emojis that match the product's energy (🌿 for wellness, 💧 for hydration, 💪 for fitness, 🧸 for cozy)

### RULE 4: Benefit Layout Options
- **3 icons in a row** (most common) — short 2-3 word label with icon above
- **Left-aligned vertical list** (premium/tech products like Theragun) — more room to explain each feature
- **Dot-separated summary line** always appears below the icons — "Lightweight • Glowy • Protected"
- Always 3 benefits minimum, never more than 4
- Benefits target USE CASES for fitness ("Travel", "Workouts") and OUTCOMES for beauty ("Clearer Skin", "Glass Glow")

### RULE 5: CTA Button Language by Niche
- **Skincare**: "Save This Routine" / "Save for Later"
- **Makeup**: "Save This Look" / "Try It Now"
- **Home Decor**: "Save This Idea" / "Get Cozy"
- **Fitness**: "Save This Routine" / "Save for Later" / "Save This"
- Pinterest CTAs should encourage SAVING, not buying — saves boost distribution

### RULE 6: Font Energy Matches Product Energy
- Cozy/warm products (blanket, lamp) → serif or mixed serif/sans headline
- Clinical/skincare → clean bold sans-serif, feels dermatologist-approved
- High-energy/tech (LED lights, Theragun) → ALL CAPS bold, sometimes neon effect
- Wellness/supplements → mixed font headline (bold sans + italic script accent word)
- Beauty/makeup → clean modern sans with emoji accents

### RULE 7: Frame It as Content, Not an Ad
- Always "Review" or "Must-Have" or "Routine" framing in title
- Description opens with a question or relatable pain point ("Looking for...?", "Struggling with...?")
- CTA is always soft and Pinterest-native: "Save", "Save for Later", "Save This Idea" — never "Buy Now"
- Add "Review" to pin title for trust: "CeraVe Moisturizing Cream Review | ..."

### RULE 8: Show What's Inside/How It Works
- Lip mask → texture swipe behind jar
- Liquid filter → open wand applicator shown next to bottle
- LED lights → dark room glowing with the lights on
- Massage gun → person actually using it on their shoulder
- Greens powder → fresh fruit ingredients surrounding the jar
- The product photo alone is never enough — show what it does or feels like
