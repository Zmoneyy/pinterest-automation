How to get your cookie (2 min)
  1. Open trends.pinterest.com in Chrome (make sure you're logged in)
  2. Press Cmd+Option+I → click Network tab → click Fetch/XHR
  3. Reload the page (Cmd+R)
  4. Click any ApiResource request in the list
  5. In the right panel → Headers → scroll to Request Headers
  6. Find the cookie row → copy the entire value
  7. Paste it below and click Save

Cookie usually lasts 1–4 weeks. You'll see a red "expired" notice when it needs refreshing.
