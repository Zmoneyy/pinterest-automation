## What We're Building

A fully automated Pinterest pin creation and posting system for Amazon affiliate marketing.

**Goal:** Auto-generate Pinterest pins, post them on a schedule, and drive traffic to Benable lists that contain Amazon affiliate links.

---

## Tech Stack (Decided)

| Step | Tool |
|------|------|
| Pin content + SEO text | GPT-4o (OpenAI API) |
| Pin image generation | Google Gemini Imagen (Google AI Studio API) — chosen because it looks more realistic/less AI than DALL-E |
| Pin posting | Pinterest API |
| Monetization layer | Benable (curated Amazon affiliate product lists) |

---

## The Full Funnel

```
Niche input (e.g. "Royal Blue & Gold Home Decor")
        ↓
GPT-4o generates: pin title, description, keywords, alt text, board name, DALL-E/Imagen prompt, variations
        ↓
Gemini Imagen generates the pin image
        ↓
Pinterest API posts the pin (linked to Benable list for that niche)
        ↓
User clicks → Benable list → Amazon affiliate links → Commission
```

## Pin Image Strategy

- Images are **AI-generated representations** of products, NOT scraped from Amazon
- No copyright issues, cleaner aesthetic, full color control
- Styled like a photoshoot/lifestyle scene, not a product catalog

**Product selection formula (for any niche):**
- 1 bold/statement item (e.g. pillow, sofa)
- 1 shiny/metallic item (e.g. mirror, candle holder)
- 1 soft texture item (e.g. throw blanket)
- 1 small accessory (e.g. vase, coaster, tray)

**5 elements to vary per pin (for scaling):**
1. Background (marble, dark navy, beige, lifestyle scene)
2. Text hook ("Looks Expensive", "Under $50", "Luxury on a Budget")
3. Product focus (pillows only, wall decor, full room setup, accessories)
4. Layout style (grid, collage, lifestyle scene)
5. Color intensity (light + airy vs dark + dramatic)

---

## Pin Output Structure (Every Pin Should Include)

1. **Title** — 60–100 chars, primary keyword first, curiosity-driven
2. **Description** — ≤500 chars, benefit-driven, soft CTA (Save/Shop/Discover)
3. **Keywords** — 1 primary + 5–10 secondary
4. **Alt text** — clear, literal image description (important for Pinterest SEO)
5. **Board name** — SEO-aligned (e.g. "Blue & Gold Living Room Ideas")
6. **Visual concept** — layout, background, color palette, font style, 1000x1500px (2:3 ratio)
7. **Text overlay** — exact headline, subtext, CTA to place on image
8. **Imagen prompt** — copy-paste ready, includes product description, lighting, background, composition
9. **Affiliate strategy** — which Benable list to link to
10. **Variations** — 3 alternate headlines, 2 alternate angles

---

## Monetization Strategy

- **Pinterest pin** links to a **Benable list** for that niche
- Benable list contains real Amazon affiliate products (curated manually, once per niche)
- Pin sells the *vibe/aesthetic*, Benable sells the *actual products*
- Do NOT use direct Amazon links in pins (Pinterest may suppress reach)

**Benable lists need to be created manually before pins go live for that niche.**

---

## Posting Strategy

- New accounts: 3–5 pins/day (weeks 1–2), then 5–10/day
- Consistency matters more than volume
- Each niche: 1 specific board + 1 broad board
  - e.g. "Blue & Gold Decor" + "Home Decor Ideas"
